## Результаты замера Debug vs Release 

| Режим   | Запуск 1 | Запуск 2 | Запуск 3 | Запуск 4 | Запуск 5 | Минимум | 
| ------- | -------: | -------: | -------: | -------: | -------: | ------: | 
| Debug   |      1445 |      1434 |      1458 |      1453 |      1458 |     1434 | 
| Release |      204 |      199 |      192 |      193 |      203 |     192 | 

В моем эксперименте Release оказался быстрее Debug примерно в 7,5 раз.
 ## Что я обнаружила при сравнении IL

При сравнении IL-кода в ILSpy было видно, что в Debug-версии присутствует множество инструкций nop, которые нужны для отладки, но не несут полезной нагрузки. В Release-версии эти инструкции отсутствуют. 

  Также в Release компилятор оптимизировал работу с локальными переменными и сократил количество промежуточных операций, что и привело к значительному ускорению выполнения программы.

  Количество IL-инструкций в методе Add() изменилось с 4 (в Release) до 10 (в Debug).
